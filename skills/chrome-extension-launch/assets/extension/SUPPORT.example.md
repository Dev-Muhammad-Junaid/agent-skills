# Distract: help and support

Distract hides the parts of YouTube, X, Facebook and Instagram you don't want. Click the Distract icon and the popup draws the page you're on as blocks. Click a block to hide that section, and click it again to bring it back.

## Getting started

1. Install Distract from the Chrome Web Store and pin it to the toolbar.
2. Open YouTube, X, Facebook or Instagram. If the tab was already open, reload it once.
3. Click the Distract icon, then click any block to hide that part of the page.

## Tips

- **Hover a block** to outline that section on the page. Hovering a hidden block shows it briefly.
- **Colours:** blue blocks are page areas, pink blocks are feed junk (Shorts, Reels, ads, suggestions), amber blocks are buttons.
- **Tabs** in the popup switch between page types (for example YouTube home and watch), so you can set up pages you're not on yet.
- **The switch** at the top pauses Distract on that site. **show all** brings everything back.
- Hiding **Shorts** opens Shorts links in the normal YouTube player. Hiding **Up next** centres the video.

## Something isn't hiding?

These sites change their layout often. If a block no longer hides its section, or something else disappears:

1. Reload the page.
2. Try pausing and resuming Distract on that site.
3. If it still happens, email the site, the page (for example "YouTube home"), and the block name to **support@example.com**.

Known limits:
- Sponsored posts inside the Facebook feed can't be detected reliably yet. The sponsored panel on the right is hidden.
- Some sections are found by their English labels. If your site language isn't English, a few blocks may show as "not on this page".
